# Reference provenance

## Singularity 2 movement study

- Source: <https://github.com/Sathvikar01/singularity2>
- Live reference supplied by the project owner: <https://singularity2.vercel.app/play/YQWZ?solo=1>
- Inspected commit: `112d9c0137d53722cb56422e999e58abf1d862ee`
- Inspected: 2026-09-05

The reference was used to study active-ragdoll motion, role response, gait cadence, recovery, camera behavior, and impact feedback. Its repository does not currently include a license or a package license field, so no source code, shaders, audio, geometry, or other assets were copied into this project. Compatible behavior is independently implemented around this project's server-authoritative deterministic simulation and existing visual identity.
